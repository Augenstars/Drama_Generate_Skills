# 短剧视频与时间线音乐提示词

所有模型和服务档位每次实际生成最多9张参考图片；原生或模式更低上限取小，视频/音频规则不变，资产库总量不限。详见[统一图片上限](../short-drama/references/model-service-presets.md#全模型统一参考图片上限)。超限不丢必要参考、不改剧情或时长、不静默换路线。

继承当前分镜的剧情、镜头职责、起终状态、时长、逐字对白和生成组，只写文本，不调用生成服务。

## 仅明确人物传记：片外形象验证

用户明确选择人物传记／名人传记且当前要对原创演员候选进行形象验证时，先读[共享规则](../short-drama/references/biography-actor-preflight.md)。本分支可在正式分镜前提供与同一图片候选配对的短片正文，依已选模型／服务、语言、模式、合法时长和参考预算写单镜少量动作；未有候选图可先完整写自行挂载计划，不编造REF、平台通过或真人身份授权。

验证短片是片外工作稿：不新增正式SHOT／MOTION／GROUP、不占成片时长、不伪造对白来源。回复或用户指定的可选分析区承载测试正文，测试句明确仅供口型验证；下文的逐镜映射、对白保留、完整正式正文与计时规则继续适用于剧集正式镜头。用户预写下游时可标候选／PLAN，不能假定形象已选定；已有选定／实测证据沿用，不因普通修订重测。原创短剧及未声明传记的请求不进入此分支。

## 先确定本轮分支

读取当前项目的已接受生产档案及当前分镜，确定目标模型/服务档位、生成模式、交付路线、正文语言和本轮是否仅准备文本。用户本轮明确选择优先；已有选择不重新询问，不因缺图改走文生视频，不改项目模型。

按[定向读取](../short-drama/references/task-reading.md)只取当前任务需要的文件段落；本轮已完整读取且未变的内容复用，截断只补缺段。不一次打印全部规则、整份长文档和检查器源码。

| 命中条件 | 本轮读取/执行 |
|---|---|
| 默认输入 | 当前分镜与必要视觉事实；对白或剧情来源需核实时读取当前剧本的对应场次，不用旧对话草稿替代文件 |
| 已选服务预设 | [模型服务预设](../short-drama/references/model-service-presets.md)中命中档位；服务规则覆盖通用默认，不把上传上限当资产库配额 |
| seedance-2.0 / 2.5 / minimax-h3 / wan-3.0 | 仅命中的[2.0](references/seedance-2.0.md)、[2.5](references/seedance-2.5.md)、[H3](references/minimax-h3.md)或[Wan](references/wan-3.0.md)方言，不读取其他方言 |
| 未有适用方言或能力有缺口 | [目标模型能力档案](references/target-model-profile.md)，未知能力如实保留，不能推断支持 |
| GROUP或mixed交付 | [交付分组](references/delivery-profile.md)的容器、唯一计数与组间接点；[成员审查格式](references/review-members.md)；不读取未命中的续接细则 |
| 新增/迁移参考或处理缺口 | [输入契约](references/input-contract.md)；已确认槽位直接继承，不重复设计参考路线 |

| 实际结果续接且起点条件成立 | [续接细则](references/continuation.md)；普通切镜独立从指定开场生成，不伪造上一段视频或尾帧 |

提示词语言优先production_profile中已接受的video_prompt_language，其次format.prompt_language；对白语言继承剧本和声音方向。用户点名模型但项目尚未记录时，由short-drama在本请求内写入已授权选择再继续，不擅自换模型。低价2.0每个实际GROUP仅5/10/15秒，组内SHOT不量化；独立提交同样遵守实际生成单位规则。冲突回分镜，不暗改边界。

## 输入和就绪边界

- 参考生视频仍填“生成方式：图生视频”；起始帧字段是开场文字，不代表存在图片，不强制逐镜先出首帧。
- 每镜输入参考图原样继承分镜的REF/PLAN、顺序、路径或条目、中文名、用途、控制和不得控制。图片提示词不是图片，未实际裁切不登记裁片。
- REF必须是真实可读且用途匹配的已核对素材；复用明确[具体原文件与选区](../short-drama/references/reference-roles.md#复用图片必须可定位)。本轮没有变动且已有有效观察时不无故重审；用户要求逐图审阅或内容有变化时按实际范围检查。对实际图像审查中的不合格图，在结果内提供[逐图问题与更正提示词](../short-drama-review/references/rubric-assets-prompts.md#图像审阅的逐图反馈与更正提示词)，不只留下缺口或口头修改方向。
- 用户自备PLAN允许继续完整文本，但不能声称文件齐备或自动投产就绪。未解决且未选PLAN的必要缺口一次列清，只停止依赖缺口的最终正文；不静默切文生。
- 只有明确选择文生视频才填“生成方式：文生视频”，无图正文必须完整给出必要静态视觉事实。只有起始图、首尾图或参考生的模式按明确选择及目标档案优先级解析，不根据图数推翻已选模式。
- 参考图只管已声明外观/地理，不搬入板格、背景、展示姿势、人数或提前出现的终态。后续人物/物件只在指定阶段生效；普通群演按群体与衣装管理，不要求逐人身份板。

## 两种MOTION，共用同一镜头边界

每镜一个`## MOTION-... · 中文名`，编号对应SHOT，不增加并行版本。

**独立提交镜头**沿用完整骨架，字段依次为“分镜、时长、生成方式、输入参考图、静态视觉锚点、起始帧、状态链、终点”，并写唯一`### 可复制提示词`引用块。静态锚点只写图片无法清楚承担的必要事实；文生视频则写完整外观并原样进入正文。不可用“保持已有外观”替代无图时的事实。

**已归组镜头**新稿采用`- 审查模式：GROUP成员`及精确`- 所属GROUP：GROUP-...`，保留来源、原绑定、起点、动作过程、景别/机位、运镜、终点、原声音与对白预算等审查信息，**不再写逐镜可复制正文**。只有实际且唯一归属、有完整正式正文的GROUP才能使用此格式，独立镜头不得借此省略正文。旧项目的完整MOTION格式继续兼容，不自动重写旧稿。细则见[成员审查格式](references/review-members.md)。

参考职责、成员到整组的编号、去重输入和累计时间从当前分镜派生，可运行[映射工具](../short-drama/references/derived-data.md)。这是可重建的辅助结果，不是新的手工资产库或创作真相，不决定剧情、分组、动作和素材合格性。工具不能解析的输入保留人工清单并说明范围，不丢弃视频/音频或未知槽位。

## 唯一正式正文

成稿遵循[摄影与表演写法](references/cinematic-writing.md)。完整的[正文检查细则](references/body-requirements.md)用于正式提交段；出现对应问题才读动作预算、可生成性或审查案例。

每个GROUP或独立MOTION只有一份正式正文。正文自包含，包含实际输入职责、开场景别/机位和可见状态、有序表演与接触、摄影机行为、声音和终点；不能用“同MOTION”“参见分镜”或“保持原设定”替代事实，不含路径、QA结论或待补占位符。引用块每个非空行以`>`开头。

参考已经清楚表达的普通脸型、衣物介绍不在字段、动作段反复扩写；正式提交段仍逐字包含适用连续性锁和图中不能承担的关键事实。相同取值且生效范围相同的事实可在GROUP共用段写一次，不将阶段状态泛化为全组。独立生成请求之间仍各自完整。

逐镜核对起点→触发→接触→承重→释放/落点→终点，明确自身左右手、持物和反应。运镜继承分镜；不能加隐藏切镜、改镜长、提前揭示人物或省掉交接。对白从首字到尾字逐字保留，在本次正式正文中按原事件次数出现；检查实际发声窗口、必要停顿和并行动作，不为凑时长删词、倍速或快读。

对白/VO/OS写说话人、口语语言、逐字文本和时机；无对白镜说明底声或静默，时间线不得凭空增加声源。来源已确认的额外发声边界合并写一次，不自造禁令。全程不生成非画内字幕、caption和对白文字叠加，除非创作者明确开启；画内允许文字逐字写承载面和阶段，不能用全局no-text覆盖。

相邻GROUP分别写本组切出阶段与下一组接入状态、方向、持物、声音和时空揭示；本组正文只写本组生成内容，声音桥/混音/字幕等后期职责放正文外。不重复已完成动作、对白和音效，不机械增转场，不增加总长之外的时间。单镜短于接口下限可作为合法GROUP成员；不是独立提交授权。

## 按需细节与完成

多人表演、口型与发声估时缺依据时读[表演与动作时序](references/performance-action-timing.md)；相邻镜头声画问题读[摄影与声音连续性](references/camera-audio-continuity.md)；动作负载/形变问题读[可生成性](references/generability.md)。补拍或版本关系读[运动配方](references/motion-recipe.md)，规则归属争议读[阶段契约](references/stage-contract.md)，具体缺陷读[审查与示例](references/review-and-fixtures.md)。不为普通任务遍历这些文件。

用户要整集就完成整集，GROUP与散镜不重不漏地只计一次。来源不变的字段和绑定直接复制，局部修改只重建受影响的派生表和正式段，再核对相邻边界。

用户明确要求时间线音乐时才加独立章节，写区间、剧情功能、进出、动态和禁用项；歌词只用已提供/接受文本，不创作歌词。静态漫剧已选关键帧切换与配音时可跳过运动正文，不改其制作形态。

检查器对分镜声音中可解析的原句补做逐字与次数核对；同一剧本声音事件跨镜延续只生成一次，分镜中的纯后期延续写明`后期声音桥：...`，不当作本组重新发声。跨组拆句、未规范发声或声源归属仍须语义核对，不能拿来源子串匹配当完整对白验收。

运行跨文档检查：只对已有文档用--partial，五份齐全后完整核对；结果通过且关键语义复核无新问题即交付，不为完美格式无界重写。每次实际修改后做必要复核，不能拿机械通过代替动作、声音或生成质量验证。技能不生成媒体；生产只能转short-drama-produce并取得该阶段要求的显式确认，GROUP成员审查记录不作为独立任务提交，当前内置工具不因本次文本修改获得自动GROUP/续写能力。
