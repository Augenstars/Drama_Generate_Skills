# 明确人物传记：类型交接与事实边界

仅用户明确要求人物传记、名人传记或以真实人物生平改编时读取；姓名、照片、写实风格和资料中的例子不触发。原创项目不增加类型选择、史料核查或演员测试步骤。

## 记录一次，后续沿用

首次明确选择传记时，无论从主路由、develop还是write直接进入，都交接这项已授权选择：

- 项目有配置：由short-drama沿既有决策写入方式，将简短的“作品类型：人物传记（用户明确选择）”及适用人物范围记入已有`creator_authority.constraints`。保留其他约束，不另造配置槽位或第二套类型登记，也不要求用户重复同意已给出的选择。
- 没有项目配置：在当前已有简报或剧本开头保存一行作品性质说明；本轮没有文档则保留在回复中，不为咨询初始化项目。以后建项目时承接该明确选择。
- 有配置时，文档里的类型说明只是引用；有新选择时同步相关说明。未明确的项目继续原流程，不把未知强制改成原创或传记。

后续assets、image-prompts、storyboard和video-prompts先核对这一短约束。没有配置记录且当前视觉设定也未交接类型时，只定点读取已有简报／剧本的作品性质说明，不为此通读整剧或开发材料。用户本轮明确选择优先；已有记录互相矛盾时只澄清实际分叉，不凭人物名字补判。

视觉中的叙事身份、原创演员候选与测试仍按[演员前置验证](biography-actor-preflight.md)处理。只做叙事时记录类型，不提前启动形象或媒体测试。

## 事实核验属于叙事阶段

本节由develop／write在新增或修改关键生平事件时执行，review在获授权的叙事审查范围内复核。纯视觉、提示词或局部服装任务继承已有结论，不自动启动全剧调查。

区分三类信息，在现有简报、剧本说明或相应段落旁用最少文字标明：

1. **已核实的生平事实**：记录足以回查的来源及日期／页码／位置；重大赛事、获奖、转会、关键关系和年代等不能仅凭输入措辞当成已核实。对不确定或可能变化的事实核对适用的一手资料，无法取得来源时如实待核。
2. **戏剧重现**：合理补足的动作、场面压缩与对白，说明重现性质；没有逐字来源的台词不冒称本人真实原话，不借重现改变重大事件结果。
3. **材料声称或未证实事项**：保留来源与具体缺口，草稿可清楚标为待核；不能在最终传记叙述中写成已发生的事实。

创作者接受某版剧情，表示接受创作安排，不自动构成史实证据。核查与已确认剧情冲突时，列明具体事件、证据和下游影响，不静默改剧情；继续不依赖该争议的工作，把必要改编选择交还创作者。明确要假设／架空表达时按其选择标明作品性质，不把假设包装成真实经历。

不强制新增史料库、逐句证据表或第六份单集文档，不为已有可靠来源反复核查。记录深度取决于本轮关键事实与真实不确定性。
