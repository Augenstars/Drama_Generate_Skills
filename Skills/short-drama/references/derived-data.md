# 从当前来源派生参考与时间数据

`scripts/reference_map.py`是只读辅助工具。直接读取当前分镜与已有视频文档，沿用既有REF/PLAN及生成组，计算去重上传次序、各成员原槽位/局部图号到整组图号、成员累计时间和素材数量。不新增分组，不重分配镜长，不生成媒体或裁片，不写正式正文，不确认素材视觉合格。

从技能目录定位脚本后运行：

```text
python <short-drama技能目录>/scripts/reference_map.py <剧集目录> --project-root <项目目录>
python <同上脚本> <剧集目录> --project-root <项目目录> --group GROUP-EP002-04 --format markdown
python <同上脚本> <剧集目录> --project-root <项目目录> --format json --output <新的临时派生文件>
```

默认只返回简短摘要；按需选择一组或输出到临时文件，避免整包表格截断。输出文件不能覆盖五份创作文档或项目配置，不自动覆盖已有文件。派生结果可随时从当前来源重建，无须另建手工资产库。

## 去重与职责

- REF按实际解析文件路径识别，同文件的多个职责合并上传但逐条保留控制/排除范围、原槽位与生效成员；不同文件即使内容相同也不按hash合并。
- PLAN只按同一IMG/SHOT计划条目合并；同一人不同造型或状态若对应不同输入，使用不同计划条目，不能借同一个条目冒充两张图。同一实际整板的不同选区可以共享一份输入，职责保留。
- 图片与音频分别从1编号，音频保留角色和音色职责。当前Markdown尚无通用视频槽位语法；出现参考视频字段时工具明确停止，保留人工编号清单，不忽略视频或宣称已支持自动绑定。
- 原始槽位顺序与本镜按文件去重后的编号不是一回事；输出同时保留两者，正文使用整组上传号。来源REF与PLAN绝不互相转换。
- 生效范围来自原控制字段和镜头范围。工具不猜后续入画、持物状态或终态；这些仍由正式正文/审查明确，不能因复用参考而扩大到全组。

## 来源和限制

已有视频文档时读取其GROUP成员并校对分镜绑定和镜长；没有GROUP时，只读取分镜每镜已明确的`生成组：GROUP-...，组内a—bs`。无法无歧义读取时报告具体问题，不从文件名/表意猜组，不把已提及但无法解析的GROUP改成散镜。

该工具验证可解析的来源、文件存在、唯一计数、同场相邻、时长相加及已知模型预算，始终输出production_ready=false。它不能替代REF内容审阅、PLAN真实挂载、音频身份检查、正文语义覆盖或生产预检。能力未知仍按原规则处理；工具不能解析时不自造输入语法，人工保留已定路线继续允许的文本工作。
