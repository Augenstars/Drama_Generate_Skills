# 当前任务的定向读取

先从本轮请求和当前项目确定阶段、已接受模型/服务、模式、交付路线与是否生产。优先级沿用各阶段现有契约，不另建选择系统，不重新询问已确认事项。

| 阶段 | 起始读取范围 | 只在需要时追加 |
|---|---|---|
| 分镜 | 当前剧本、必要视觉事实、命中服务/节奏要求 | 对应场次调度、实际参考和镜长依据；已有图像提示词只为核对引用 |
| 图片提示词 | 当前视觉设定及目标资产、已提供参考 | 剧本状态、受影响分镜、命中服务的参考预算；不遍历无关资产 |
| 视频提示词 | 当前分镜、必要视觉事实、已选方言和交付分支 | 剧本对白来源；新增参考的绑定细则；实际有音频才读音色规则；成立续接才读续接规则 |

明确传记的类型交接按[类型与事实边界](biography-context.md)读取现有项目约束；无记录时只核对现有简报／剧本开头的性质说明。名称、照片或示例不替代用户选择。只做视觉或提示词时不因此展开生平调查。

## 读取与复用

1. 同一轮已经完整读取且文件未变时复用当前内容；修改、来源不明、内容截断、用户要求重审或出现矛盾时，再读取所需部分。当前文件始终优先于历史摘要。
2. 先定位标题/字段，再按场次、镜头或GROUP取段。并行读取仅用于独立输入，并限制各结果和外层合计返回量，避免整包打印后被截断。
3. 截断不视为已读；只补缺失范围，不再全量打印同一大包。图像按本轮要求与实际变化逐张检查，不能用文件名、旧摘要或工具派生数据冒充像素审阅。
4. 正常制作先执行既有检查器；仅错误原因不明确或正在维护程序时读取其相关源码。不把整个技能库、维护备份、所有模型方言和测试源码当作默认输入。
5. 既定镜头、参考职责和时长等重复数据从当前来源直接复制/派生；只有确需创作的表演和正式正文交由模型重写。局部修改核对受影响条目及接点，不无故全量重写。
6. 任务跨阶段或上下文压缩时，可在现有交付说明保留短状态：来源文件、已选模型/模式、镜头/组范围、必要PLAN/缺口和最近实际检查。它不是新的强制文档或创作真相；不能以摘要替代需要重新核对的当前源文。

不设统一文件数、读取次数、输出字数、检查次数或分钟限额。必要事实多时照实际范围完成；来源变化后重新检查，结果通过且无新问题时停止扩展。该规则优化执行方式，不减免原有真实性、完整性、连续性或授权边界。
